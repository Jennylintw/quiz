# 優潤家｜包租天賦四型

線上課程用的天賦定位與組隊心理測驗。8 題找出你的鳥型，產出可儲存的定位卡，
並協助你找到互補的隊友。

**線上版：** https://jennylintw.github.io/youroom-quiz/

## 內容

- 🦅 獵鷹型｜開疆獵房家 — 看見機會
- 🦉 軍師型｜精算操盤家 — 判斷機會
- 🦚 築夢型｜空間鍊金師 — 創造價值
- 🐧 管家型｜幸福經營家 — 守住價值

> 一個人不需要成為四種鳥；一個團隊，需要四種人才。

## 技術說明

`index.html` 是**單一自足檔案**——角色圖、品牌 logo 全部以 base64 內嵌，
沒有任何外部相依（字型走 Google Fonts CDN，載不到會自動退回系統中文字型）。
直接開檔或放到任何靜態主機都能跑。

要修改內容的話，原始模板與打包腳本（`_template.html` + `build.py`）留在本機專案資料夾，
改完跑 `python build.py` 重新產生 `index.html`，再推上來即可。
